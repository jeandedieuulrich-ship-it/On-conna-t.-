# ON CONNAÎT 🇨🇮 - Tout ce qui se passe en Côte d'Ivoire

Bienvenue sur le dépôt officiel de l'application **ON CONNAÎT 🇨🇮**, la plateforme de référence pour découvrir tous les événements, concerts, festivals, salons, expositions et trouver les meilleurs prestataires professionnels vérifiés en Côte d'Ivoire.

---

## 🌟 Fonctionnalités Principales

### 1. 🎟️ Événements & Spectacles
- **Fiches complètes** : Nom, affiche HD, catégorie, description, date, jour, horaires, lieu, commune, ville, adresse, géolocalisation GPS, tarifs en FCFA (ou mention 100% Gratuit), programme détaillé heure par heure, intervenants/artistes et jauge de places.
- **Actions interactives** :
  - Contact direct avec l'organisateur (Appel et WhatsApp avec message pré-rempli).
  - Export vers Google Agenda et téléchargement de calendrier (.ics).
  - Partage sur les réseaux sociaux.
  - Signalement communautaire des informations erronées.
- **Lieux emblématiques intégrés** : Parc des Expositions d'Abidjan, Palais de la Culture Bernard Dadié, Sofitel Hôtel Ivoire, Canal Olympia Yopougon, Stade Félix Houphouët-Boigny, etc.
- **Couverture nationale** : Grand Abidjan (Cocody, Yopougon, Plateau, Marcory, Treichville, Port-Bouët...), Yamoussoukro, Bouaké, Grand-Bassam, San-Pédro, Korhogo, Assinie, Daloa, Man.

### 2. 🎨 Expositions, Art & Musées
- Musée des Civilisations de Côte d'Ivoire (MCCI), Fondation Donwahi, Biennale Photo de la Rotonde des Arts, Musée National du Costume de Grand-Bassam, poteries de Katiola, toiles sacrées de Fakaha / Korhogo, et Babi Street Art.

### 3. 🎤 Concerts Live en Côte d'Ivoire
- Zouglou authentique (Yodé & Siro, Magic System), Afrobeat & Variété (Josey, Roseline Layo), Rap Ivoire (Didi B, Suspect 95, Himra, Team Paiya), Reggae (Alpha Blondy, Tiken Jah Fakoly), Coupé-Décalé (Kerozen) et Gospel chrétien (KS Bloom, Morijah).

### 4. 💼 Salons Professionnels & Économiques
- ARCHIBAT (Architecture & Bâtiment), SITA (Tourisme), SILA (Livre), SARA (Agriculture), SIPME (PME & Startups), SIEFO (Étudiant & Grandes Écoles), SEIP (Épargne & Investissement), SIBBE (Beauté & Cosmétique Africaine) et SIREXE (Énergie & Mines).

### 5. 👨🏾‍💼 Annuaire des Prestataires Événementiels
- Photographes, Vidéastes, DJ, Traiteurs, Décorateurs, Animateurs/MC, Wedding Planners, Location de voitures de cortège, etc.
- Vitrine publique avec portfolio, formules tarifaires « à partir de », avis clients et badge « Profil vérifié 🛡️ ».
- Formulaire interactif de demande de devis personnalisé envoyé directement sur le tableau de bord du prestataire.

### 6. 💳 Modèle d'Abonnement Prestataires & Mobile Money
- **3 mois d'essai gratuit** offerts à tout nouveau prestataire pour lancer son activité sans engagement.
- **2 000 FCFA / mois** après la période d'essai pour continuer à vendre ses services.
- **Moyens de paiement intégrés avec liens directs et codes USSD** :
  - 🌊 **Wave** : `05 74 00 39 03`
  - ⚡ **MTN Mobile Money** : `05 74 00 39 03` (*133#)
  - 🍊 **Orange Money** : `07 57 34 62 16` (#144#)

### 7. 🛡️ Inscription Sécurisée & Protection des Données (Loi n°2013-450 / ARTCI)
- Séparation stricte entre les données professionnelles publiques et les documents d'identification personnels (CNI, passeport, RCCM, date de naissance) conservés en coffre-fort numérique sécurisé.
- Respect rigoureux des droits d'accès, de rectification et de suppression encadrés par l'ARTCI.

### 8. 📍 « AUTOUR DE MOI » & 🗺️ Carte Interactive de Côte d'Ivoire
- Géolocalisation avec calcul de distance en temps réel (Haversine) et filtre par rayon ajustable (< 2 km à 50 km).
- Carte interactive cliquable de toutes les régions ivoiriennes.

### 9. 🇫🇷 / 🇬🇧 Bilinguisme & Touche Culturelle Ivoirienne
- Switcher instantané Français / Anglais.
- Couleurs nationales (Orange, Blanc, Vert), design chaleureux et expressions authentiques ivoiriennes (*« C'est gâté ! »*, *« Abidjan est doux ! »*, *« On est ensemble ! »*, *« Y'a fohi »*).

## 🛠️ Stack Technique

- **Frontend** : React 19, TypeScript, Vite
- **Styling** : Tailwind CSS, Lucide React (Icônes)
- **Animations & Effets** : Canvas-Confetti, Motion
- **Architecture** : Context API avec persistance locale sécurisée, séparation des rôles (Visiteur, Organisateur, Prestataire, Administrateur).

## 🚀 Installation & Lancement Local

Copiez et collez ces commandes dans votre terminal :

```bash
# 1. Cloner le projet depuis GitHub
git clone https://github.com/jeandedieuulrich-ship-it/On-conna-t.-.git
cd On-conna-t.-

# 2. Installer les dépendances
npm install

# 3. Lancer le serveur de développement en local
npm run dev

# 4. Compiler pour la production
npm run build
```
